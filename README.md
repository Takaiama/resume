# resume.takaiama.ru

Статичное резюме — одна страница, без сборки и зависимостей.
По структуре повторяет `resume.kosumosu.ru`, наполнение — из
`Чернов Андрей Владимирович.docx`.

## Состав

```
index.html        вся разметка
styles.css        стили + адаптив + печать в PDF
resume.js         разбор jobs.txt, стаж, возраст, анимация, кнопка «Скачать PDF»
jobs.txt          ← ОПЫТ РАБОТЫ: единственный файл, который надо править
assets/photo.jpeg фото из docx
assets/favicon.svg
CNAME             resume.takaiama.ru — для GitHub Pages
```

Внешних зависимостей, кроме шрифта Inter с Google Fonts, нет.
Если Google Fonts недоступен — подхватывается системный Segoe UI, вёрстка не ломается.

## Деплой (GitHub Pages)

1. Создать репозиторий `Takaiama/resume` (public).
2. Залить в него всё содержимое этой папки в корень ветки `main`:

   ```bash
   git init
   git add .
   git commit -m "Resume site"
   git branch -M main
   git remote add origin https://github.com/Takaiama/resume.git
   git push -u origin main
   ```

3. Репозиторий → **Settings → Pages**:
   - Source: `Deploy from a branch`
   - Branch: `main`, папка `/ (root)` → **Save**
4. Через 1–2 минуты сайт поднимется на `https://takaiama.github.io/resume/`.

## DNS (Timeweb)

Домен `takaiama.ru` уже на NS Timeweb, apex смотрит на GitHub Pages
(185.199.108.153 … 185.199.111.153). Для поддомена нужна одна запись:

| Тип   | Имя      | Значение              | TTL  |
|-------|----------|-----------------------|------|
| CNAME | `resume` | `takaiama.github.io.` | 300  |

В панели Timeweb: **Домены → takaiama.ru → DNS-записи → Добавить запись**.
Имя писать без домена — просто `resume`. В конце значения точка не нужна,
панель подставит сама.

## SSL

1. После того как DNS разошёлся (5–30 минут, проверить:
   `nslookup resume.takaiama.ru`), зайти в **Settings → Pages**.
2. В поле **Custom domain** вписать `resume.takaiama.ru` → **Save**
   (файл `CNAME` в репозитории уже лежит, поле подтянется само).
3. Дождаться статуса «DNS check successful».
4. Включить **Enforce HTTPS** — сертификат Let's Encrypt GitHub выдаёт
   автоматически, обычно в течение 15 минут.

Проверка после включения:

```bash
curl -sI https://resume.takaiama.ru | head -1   # HTTP/2 200
```

## Как править контент

### Опыт работы — через `jobs.txt`

Блок «Опыт работы» целиком берётся из `jobs.txt`. Чтобы добавить новое место:

1. Открыть `jobs.txt` любым блокнотом (кодировка UTF-8).
2. Скопировать любой блок от `[РАБОТА]` до последней строки `Пункт:`.
3. Вставить копию **самой первой** — сразу после шапки с решётками.
   Порядок блоков в файле = порядок на сайте.
4. Заполнить поля, лишние строки удалить, сохранить, обновить страницу.

Поля: `Начало` (ГГГГ-ММ, обязательно), `Конец` (пусто = «настоящее время»),
`Организация` (обязательно), `Город`, `Должность`, `Отрасль`, `Подпись`,
`Объект` (можно много — станут карточками), `Разделы`, `Пункт` (можно много — станут списком).
Строки, начинающиеся с `#`, игнорируются. Срок на каждом месте и общий стаж
считаются по датам автоматически.

Блоки в `index.html` — резервная копия на случай, если `jobs.txt` не загрузился
(например, страница открыта двойным кликом с диска, где `fetch` запрещён).
На хостинге всегда используется `jobs.txt`.

### Остальное — в `index.html`

Шапка, «Обо мне», навыки, образование, дополнительно — обычным текстом.
Возраст считается из `data-birth`.

### PDF

Кнопка «Скачать PDF» в шапке → печать браузера → «Сохранить как PDF».
Стили печати настроены под A4 (4 страницы), тёмные блоки при печати становятся светлыми.
